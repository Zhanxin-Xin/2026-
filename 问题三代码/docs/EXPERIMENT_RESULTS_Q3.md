# 问题三完整实验结果

## 1. 结论先行

正式 EXP183 在冻结测试集 727 个样本上取得：Accuracy **0.7331**、Macro-F1 **0.6903**、Weighted-F1 **0.7273**、Balanced Accuracy **0.6890**、MAE **0.5309**、RMSE **0.7198**、Bias **0.0073**、Pearson **0.7831**。这组数值来自 `runs/final_test/exp183_neutral_authenticity_arbitrator/final_test_metrics.json`，是论文主结果。

注意：父共识在 test 上事后为 0.7345/0.6970，但该结果在 EXP183 冻结之后才可见，不能据此更换正式模型。论文可把它列为“冻结后描述性参照”，不能写成重新选择后的最终方案。

相对单一 C³-HAFusion，EXP183 的 Accuracy 提升 0.0674，Macro-F1 提升 0.0811，MAE 下降 0.0866，Pearson 提升 0.0843。这说明提升来自异构证据互补和冻结仲裁部署，而不是只修改单一网络参数。

533 个样本分类正确；145 个错误属于 Neutral 边界混淆，占全体 19.94%；49 个属于正负极性反转，占 6.74%。Neutral F1 只有 0.4948，是 Macro-F1 未超过 0.70 的主要原因。极性反转样本平均绝对回归误差为 1.3158，显著高于正确样本的 0.4440，说明这类错误同时破坏方向和强度。

## 6. 最终管线模态遮挡

对 EXP183 冻结 test 全体 727 个样本执行真实七成员推理与同一仲裁器：

| Condition | Accuracy | Macro-F1 | MAE | Pearson |
|---|---:|---:|---:|---:|
| Full | 0.7331 | 0.6903 | 0.5309 | 0.7831 |
| Without text | 0.3906 | 0.3594 | 0.8689 | 0.2394 |
| Without audio | 0.7318 | 0.6710 | 0.5350 | 0.7841 |
| Without vision | 0.7263 | 0.6843 | 0.5339 | 0.7783 |

归一化平均作用程度为 Text 0.7398、Audio 0.1362、Vision 0.1240；主要参考模态分别为 Text 612 个（84.18%）、Audio 65 个（8.94%）、Vision 50 个（6.88%）。文本是总体主导证据，但 Neutral 样本的平均作用程度变为 T/A/V = 0.6025/0.2344/0.1631，音视频在 Neutral 边界上的补充作用明显高于强极性样本。

## 7. 连续强度与分类—回归一致性

EXP183 的 test MAE 为 0.5309，Pearson 为 0.7831，Bias 仅 0.0073，整体没有明显单向高估或低估。使用 validation 独立选择 \(\varepsilon=0.149\) 后，test 分类—回归一致率为 **0.8762**；回归符号单独映射到三类的 test Accuracy 为 **0.7345**。该指标只用于一致性诊断，不反向修改正式分类输出。

## 8. 局部证据与删除验证

最终系统没有统一注意力层，因此局部解释直接在冻结部署图上做删除。对六个按真值类别和对错分层选择的 test 案例，每个有效位置分别删除并计算置信度/强度变化，再做 10%、20%、30% 的 top/random/bottom 联合删除。以文本为例，删除 top 位置的置信度下降曲线明显高于随机和 bottom，说明筛出的局部文本证据确实控制最终输出。该结论是案例级忠实性证据，不外推为 727 个样本的总体统计。

附件4的 20 个样本也全部完成单位置删除与联合删除。删除 top 10% 文本位置时，平均冻结类别置信度下降 0.2288、预测翻转率 0.35；随机删除对应 0.0192 和 0.10；bottom 删除对应 -0.0046 和 0。这一对照支持局部文本解释的忠实性。附件4无标签，因此这些是响应变化而非准确率。

## 9. 附件4结果

附件4 20 个无标签样本全部推理成功，20/20 找到原视频。预测类别分布为 Negative 6、Neutral 3、Positive 11；主要参考模态为 Text 18、Vision 2、Audio 0。平均全局作用程度为 Text 0.7735、Audio 0.0767、Vision 0.1497。

完整表包含：样本编号、三类概率、预测强度、三模态作用程度、主要模态、局部关键位置、关键文本、音频/视觉比例时间区间和视觉关键帧路径。比例时间区间是用有效对齐位置和视频总时长计算的近似，不是官方帧级时间戳。

## 10. 结果边界

1. 正式模型满足用户后续放宽的 test Accuracy 与 Macro-F1 均超过 0.69，但 Macro-F1 没有超过 0.70。
2. 不得把父共识的事后 0.6970 Macro-F1 用来替换 EXP183；那会构成按 test 选模型。
3. 现有融合路线比较是真实历史结果，但编码器规模与训练预算并不完全相同，不能称为严格等容量公平基准。
4. 局部 test 删除只覆盖六个典型案例；总体模态遮挡覆盖全部 727 个 test 样本。
5. 74 维语音和 35 维视觉只称作赛题提供的时序表示，不赋予未经证实的物理维度语义。
