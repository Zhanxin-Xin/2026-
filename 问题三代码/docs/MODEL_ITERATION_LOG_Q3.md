# 问题三模型演化记录

## 1. 演化原则

每条路线都先在 train/grouped OOF 与 validation 上做结构判断；EXP183 冻结后一次性读取 test。test 的事后现象不再用于改选模型。

## 2. 关键阶段

| 阶段 | 代表实验 | 模型级变化 | 证据与结论 |
|---|---|---|---|
| 基线复现 | EXP000 | 三模态 C³-HAFusion | test 0.6602/0.6136，确认训练与指标管线 |
| 模态诊断 | EXP001 | 去除弱 audio，保留 text+vision | test 0.6795/0.6358，证明音频无条件融合可能干扰分类 |
| 损失/容量检查 | EXP003–008 | 分类权重、dropout、类权重、容量、耦合、Focal | 收益不稳定；三随机种子确认 Focal 对 seed 敏感 |
| 预训练语义证据 | EXP016–029 | DeBERTa、上下文、原型、多模态路由 | 单成员泛化显著提升，为异构集成提供互补证据 |
| NLI/Neutral 专家 | EXP040–075 | 标签语义、Neutral hurdle、NLI 关系 | Neutral 表征改善但单专家仍有域偏移 |
| 严格 OOF 集成 | EXP095–169 | 视频组隔离 OOF、固定七成员、投票/概率共识 | EXP169 OOF 0.6916/0.6635，valid 0.7047/0.6852 |
| 真实性仲裁 | EXP181–183 | 只对父预测 Neutral 的样本做 OOF 真实性逻辑回归，valid 冻结阈值 | EXP183 OOF 0.6919/0.6638，valid 0.7115/0.6908；随后一次性 test 0.7331/0.6903 |
| 冻结后解释 | Q3 audit | 七成员管线级模态遮挡、局部删除、附件4全量推理 | 不改变模型；补齐可解释性与交付链 |

## 3. 被否决路线

- 过度紧凑的 gated V2 欠拟合并产生文本门塌缩。
- 强回归—分类耦合在 validation 上过度预测 Polar。
- 外部情感教师、跨视频检索、普通 R-Drop、绝对 Neutral 锚点等路线未超过严格 OOF 门槛。
- 多种后验偏置和阈值搜索容易验证集过拟合，因此不进入正式结构。
- EXP184 以后的研究路线保留源码和失败证据，但没有依据 test 取代 EXP183。

## 4. 最终保留创新点

1. 面向异构证据的七成员固定共识，而非单一模型堆叠后再用 test 选择。
2. 只在父级 Neutral 决策上工作的真实性仲裁，并保持非 Neutral 决策及正负赔率不变。
3. 基础 C³-HAFusion 的冲突感知、保守残差和反事实校准结构。
4. 最终部署管线级遮挡/局部删除解释，避免把单成员注意力错误当成集成模型解释。
5. 从局部对齐位置到文本、比例时间和视觉关键帧的可复核映射。

完整逐实验记录仍保留在 `experiments.md` 和 `RESEARCH_ARCHITECTURE_LOG.md`。
