EXP105 replaced EXP104 with a fold-local phased recipe: train the EXP020 parent
for three fixed epochs, transfer only compatible weights inside that fold, train
the new EXP027 dynamic router for one fixed epoch, and then evaluate its held-out
video groups. The completed result was 0.6707 accuracy / 0.6451 Macro-F1, so the
branch was not promoted. EXP108 then supplied an independently cross-fitted NLI
Neutral-hurdle expert. Although weak alone, its diversity improved the uniform
five-expert parent in both OOF and locked validation (EXP109/110).

The next structural gate is stricter than the router's generic parent gate: any
level-two candidate over EXP109 must exceed both 0.6884 OOF accuracy and 0.6614
OOF Macro-F1 before its validation sources are loaded. EXP111/112 failed that
joint gate. EXP113 also failed it despite directly optimizing a soft per-class
F1 surrogate, so this low-capacity level-two router family is closed rather than
subjected to scalar loss-weight tuning. Reports for the sparse EXP103/112 runs were corrected to state that
zero-parameter initialization is uniform over each fold's eligible experts, not
identical to the full uniform parent; predictions and metric values were not
changed.
